# Котёл39 — сайт сервиса отопительного оборудования

Многостраничный сайт сервиса по ремонту и обслуживанию котлов в Калининграде. Проект включает главную страницу, цены, сертификаты, контакты и политику конфиденциальности.

**Демо:** https://phil-cody.github.io/kotel/

## Возможности

- отдельные страницы и общая навигация;
- адаптивная вёрстка;
- интерактивные меню и секции с часто задаваемыми вопросами;
- заполнение страниц данными из JavaScript-модулей;
- стили на SCSS с разделением по компонентам и страницам.

Данные сайта хранятся в проекте. В текущей версии запросы к backend/API не выполняются.

## Стек

HTML, SCSS, JavaScript (ES modules), Webpack.

## Локальный запуск

Нужны Node.js и npm.

```bash
git clone https://github.com/phil-cody/kotel.git
cd kotel
npm install
npm run dev
```

Production-сборка: `npm run prod`. Для локальной разработки с автоматической пересборкой: `npm run watch`.
